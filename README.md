# DFusMol: Predicting Molecular Properties Based on Dual-Channel Attention

This project provides an implementation of DFusMol, a model designed for predicting molecular properties using a dual-channel attention mechanism.

## Getting Started

To get started with the project, clone the repository and install the required dependencies.

## Usage

To run the fine-tuning process, execute the following shell script from your terminal:

```bash
bash finetune.sh
